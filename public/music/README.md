# Built-in piano scores

See CREDITS.json for the exact source pages, original download URLs, composer, uploader/collector where provided, edition notes, original SHA-256, selected track indices, excluded-track reasons and source license statement. Track and group counts and the default song are read from the catalogue; an undeclared source license is never labelled Public Domain.

The original and JSON conversion of Chopin's Nocturne Op.9 No.2 (Mutopia 1590), maintained by Renato Biolcati Rinaldi, retain Creative Commons Attribution-ShareAlike 3.0 Unported: https://creativecommons.org/licenses/by-sa/3.0/ and https://creativecommons.org/licenses/by-sa/3.0/legalcode . The license applies to that music data independently of the website software. The other listed Mutopia editions retain their source's Public Domain declaration.

Conversion by KelyCrane's blog using @tonejs/midi: the original tempo map determines note and CC64 event times in seconds. Sound-release times follow sustain events, while key-release times stay unchanged. CC7 channel volume and CC11 expression at note onset multiply the MIDI velocity; controls in separate metadata tracks still apply to the same channel. Missing controls use multiplier 1. Zero controller gain is preserved as silence. A controller change during an already sounding note is not synthesized as continuous gain automation.

Only explicitly selected performance tracks are converted. Percussion, duplicate exported tracks and unexplained exclusions fail the import. An explicit documented instrument mapping is needed for a source whose GM patch is not a piano patch. No performance notes are dropped or transposed. Sources with zero-duration or out-of-range performance notes fail instead of being silently repaired. All selected note counts and source hashes are checked.

Regenerate with npm run import:music. source/*.mid files remain unmodified; scores/*.json are fetched from this site only on playback. No third-party audio recording is included. Piano sample attribution is separately in audio/piano/CREDITS.txt.
Clouds Chasing the Moon uses the complete public EOP 2.01 source from hsdllcw/everyonepiano-music-database (Everyone Piano teaching edition). The unmodified .eop is included beside the generated import .mid, with both hashes recorded. Regenerate the import MIDI with:

    node scripts/convert-eop.mjs public/music/source/clouds-chasing-moon.eop public/music/source/clouds-chasing-moon.mid

The original strict reader follows the documented EOP 2.01 file format at https://github.com/emizuki/eop2midi/blob/main/specification.md . It refuses unsupported layouts, unknown/control events, invalid ranges, timing anomalies or unbalanced keys. This source contains 2980 note events / 1490 notes and no pedal events. Separate source-key tracks prevent overlapping same-pitch presses from being paired incorrectly. Every pitch, velocity and onset/release is compared after writing and re-parsing the MIDI; timing quantization is at most one 1/48000-second tick. The source EOP, generated import MIDI and converted JSON are distinct artifacts; no source MIDI download is claimed for this piece.
