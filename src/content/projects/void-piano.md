这架钢琴是博客的入口，也是一个可以停留的地方。你可以随手弹几个音，选一首熟悉的曲子，或只是转动视角，看看那些缓慢升起的光。

白色琴身与悬浮琴盖的构图，来自最初提供的参考图片。网页中的琴体、琴键与虚空效果由程序重新构建，参考图没有被贴在模型上，也没有作为背景代替三维场景。

## 一架真正能弹的钢琴

键盘包含从 A0 到 C8 的 88 个键：52 个白键、36 个黑键。每个琴键都有独立的转轴和按压状态，声音与下压动画对应同一个音符。点击、松开、连续重复和多指和弦，都是这套接口的一部分。

电脑上，左键拖动非琴键区域可以旋转；右键或 Shift 加左键可以平移；指向钢琴滚动滚轮可以缩放。手机和平板上，单指旋转，双指从非琴键区域开始捏合缩放或同向拖动平移；从琴键起手的触点用于弹奏。靠近键盘后，还可以使用放大的平面键盘。

默认不会发声。第一次弹奏或点击播放时，浏览器才启动音频。

## 琴体：用几何描述轮廓

场景使用 [Three.js](https://threejs.org/)。琴体外轮廓由贝塞尔曲线组成，内部挖空，再通过带倒角的挤出几何生成边框与悬浮琴盖。琴腿、踏板与琴键组合使用基础几何；白色材质、柔和照明和地面阴影让它们落在同一个空间里。

琴键的位置按钢琴的黑白键规律排列，以 MIDI 音高编号连接声音与模型。按键时只转动对应琴键，松开后用平滑插值回弹。这里没有下载现成的钢琴模型。

## 虚空：分层雾气与向上的光

琴身内的蓝色深处是一段定制的 GLSL 着色器。它使用三维噪声和多层分形布朗运动（fBm）叠出缓慢变化的纹理；沿观察方向累积 12 层密度，并随视角改变纹理偏移，产生有纵深的雾气。弯曲的噪声坐标，让流动不只是整张纹理平移。

那些向上升起的细痕由 64 个复用几何的实例组成。它们始终面向镜头，长度、颜色和起始相位各有差别，亮度沿中心与两端渐隐；少量微尘补充空间感。光痕的位置被限制在琴体轮廓内部。

这是为网页定制的视觉动画：雾气由分层采样近似，光痕按时间循环上升，并非真实流体模拟。细而轻的上升感，是这一版最终保留下来的方向。

## 声音：让每次按键都有自己的余韵

声音部分使用 [Tone.js](https://tonejs.github.io/) 及浏览器的 Web Audio。音色来自 Alexander Holm 的 [Salamander Grand Piano](https://github.com/sfzinstruments/SalamanderGrandPiano)，采用 [Tone.js 音频仓库提供的 MP3 版本](https://github.com/Tonejs/audio/tree/master/salamander)，遵循 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。本站托管 26 个采样，通过最近音高的采样与变速播放覆盖 88 键。

相差一个半音，播放速率乘以 `2^(1/12)`；A4 对应 440 Hz。按键力度影响发声强弱，每次起音建立独立声音实例，松键后平滑衰减。手动弹奏和歌曲演奏分别持有自己的声音与按键状态，因此你可以跟着歌曲一起弹，同一个音也不会被另一方的松键截断。

## 自动演奏：声音与琴键共用一条时间线

内置曲库分为“我的歌单”和“经典曲目”。原始 MIDI 在导入阶段用开源 [@tonejs/midi](https://github.com/Tonejs/Midi) 解析，转换为包含音高、起止时间、力度与延音踏板的本站数据。浏览器只在需要时加载所选曲目。

播放以音频时钟为准，提前调度短时间窗口内的声音，再按同一时间线更新三维琴键、放大键盘与进度。延音踏板延长声音，琴键仍在实际松键时回弹。暂停、拖动进度或切歌时，会取消旧调度；续播和跳转会恢复目标位置仍应持续的音符。

曲终停止，单曲循环默认关闭。下滑读文章时可以继续听；切到后台后暂停，回来由你手动继续。全部曲目的版本、制谱或整理者、原谱与转换记录，均保存在[素材致谢](/credits/#music)中。

## 交互与性能的取舍

鼠标和触摸都通过射线检测确定落点。触点从琴键开始就负责弹奏，从非琴键区域开始才参与视角手势，避免边转动画面边误触发琴键。观察中心、距离和俯仰角都有范围限制，“初始视角”恢复整套视角状态。

渲染分辨率设有上限，光痕复用实例，琴体材料与几何尽量共享。钢琴离开可视区域时暂停三维渲染，再次出现时按当前歌曲状态同步琴键。不能创建 WebGL 场景时保留静态封面、播放器和平面键盘，文字内容仍然可以阅读。

博客本身使用 [Astro](https://astro.build/) 构建静态页面，以 Markdown 保存文章，以 [Pagefind](https://pagefind.app/) 提供本地搜索，经 GitHub Actions 发布到 GitHub Pages。音色和乐谱随网站托管，播放不需要外部音乐服务。
